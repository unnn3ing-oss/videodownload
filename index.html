      安裝 YT批量下載器

      只要做一次、約 3 分鐘。裝好後這個畫面會自動消失。

      步驟 1／4

      下載安裝檔

      只需要一個安裝檔：它會安裝下載要用的元件、放好擴充功能的資料夾、測試能不能用，再打開 Chrome 的擴充功能頁。你只要在電腦上授權它執行一次。

      Mac（建議）：複製下面這一行，貼到「終端機」（按 Cmd+空白鍵，輸入「終端機」）再按 Enter。不用下載、不會跳出 macOS 的安全性提示。

      下載 Windows 安裝檔 改下載 Mac 安裝檔（備用）

      步驟 2／4

      執行安裝檔（授權一次）

      Windows：到「下載」資料夾雙擊 install-windows.cmd。若出現 SmartScreen「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。

      Mac：在終端機貼上剛才複製的指令。若用的是下載的安裝檔：解壓縮後對 install-mac.command 按右鍵 →「打開」。

      接著安裝檔會自己做完：

      1. 跳出視窗，讓你選擇要把擴充功能放在哪個資料夾（會在裡面建立一個「YT批量下載器」資料夾；不選就放在使用者資料夾）。
      2. 下載並檢查需要的元件，測試下載助手能不能被 Chrome 啟動。
      3. 最後打開 Chrome 的「擴充功能」頁和那個資料夾，並列出每一項的檢查結果。

      之後遇到任何問題，重新執行安裝檔就會自動檢查並修復；它會沿用同一個資料夾，不會再問。

      步驟 3／4

      載入擴充功能

      安裝檔已經替你打開 Chrome 的「擴充功能」頁和擴充功能資料夾。在這一頁把資料夾載入：

      1. 把右上角的「開發人員模式」打開。
      2. 按左上角的「載入未封裝項目」。

      沒有用安裝檔放擴充功能？自己部署

      先在電腦上建一個放擴充功能的資料夾（名稱同上），按下面的按鈕選它，網頁會把最新版擴充功能的檔案寫進去；也可以改下載 ZIP 自己解壓縮。再到 chrome://extensions（可以按按鈕複製）載入未封裝項目。下載助手仍要用安裝檔安裝。

      步驟 4／4

      完成

      擴充功能載入後會自動連線，不用重新整理。確認一切正常，這個視窗會自動關閉。沒有反應時再按「啟動」。

      網頁會逐項檢查哪裡還沒好，並告訴你下一步。
