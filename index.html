小程式連不上或下載有問題時，先按這裡看哪一項有狀況。還是不行，重新執行安裝檔（步驟 3）就會自動檢查並修復。

    還沒偵測到擴充功能。請先照左邊的步驟 1、2 部署並載入；完成後這裡會自動解鎖，不用重新整理。這個網頁需要 Chrome（電腦版）。

      清單是空的。貼上網址按「增加」，影片的標題和封面會自動帶進來。

      設定流程

      照順序完成四個步驟。完成並確認能下載後，這個視窗會自動關閉。

      1. 1
        部署擴充功能 建立一個空的資料夾（建議就用下面這個預設資料夾），網頁會把最新版擴充功能寫進去，也可以改下載 ZIP。

        ✓ 已完成

      2. 2
        在 Chrome 載入 開啟 chrome://extensions，打開「開發人員模式」，按「載入未封裝項目」，選剛才的資料夾（用 ZIP 要先解壓縮）。

        ✓ 已偵測到擴充功能

      3. 3
        部署本機小程式 安裝檔也是修復工具：之後遇到任何問題，重新執行它就會自動檢查並修復，最後列出每一項的結果。
        Mac：複製下面這一行，貼到「終端機」（按 Cmd+空白鍵，輸入「終端機」）再按 Enter。不用下載、不會跳出 macOS 的安全性提示。
        Windows：下載後雙擊，若出現 SmartScreen 按「其他資訊」→「仍要執行」。

        ✓ 已安裝

      4. 4
        連線 安裝完成後會自動連線，不用重新整理。沒有反應時再按「啟動」。

        ✓ 已連線
