# YouTube 批量下載器

Chrome 擴充功能加本機小程式，用來把**公司 YouTube 頻道的公開影片**批量下載到自己的電腦（720p 或 1080p），檔名直接使用影片標題。下載走你自己電腦的網路，不經過雲端。

> **使用前請先確認**：YouTube 條款原則上不允許用官方功能以外的方式下載；影片裡的音樂與外部素材，授權範圍可能只限 YouTube。請先取得頻道管理部門同意，轉發到其他平台前也請確認授權。如果管理部門能直接提供成品原檔，畫質會比從 YouTube 抓下來的更好。

## 限制（先看這裡）

- 不使用登入 cookies，只能下載公開影片與「不公開連結」影片；私人、會員專屬、年齡限制影片會失敗並顯示原因。
- 這個工具在開發環境**只驗證了邏輯與擴充功能介面**（含假的下載引擎）。**真實下載 YouTube、安裝檔在真實 Windows／Mac 上的行為，尚未驗證**，請依下面的「冒煙測試」跑一次。
- 只支援 Chrome 110 以上、Windows 與 Mac。

## 安裝

### 1. 載入擴充功能（Windows、Mac 相同）

1. 取得這個專案的 `extension` 資料夾。
2. Chrome 開啟 `chrome://extensions`，右上角打開「開發人員模式」。
3. 按「載入未封裝項目」，選擇 `extension` 資料夾。
4. 把擴充功能釘選到工具列。之後點工具列上的圖示，就會在視窗右側開啟**側邊面板**，切換分頁也不會消失。（Chrome 啟動時可能提示「停用開發人員模式擴充功能」，請選保留。）

### 2. 下載部署（只需做一次）

點工具列的擴充功能圖示打開側邊面板，按**「下載部署」**，會依你的系統取得對應的安裝檔。

**Windows**
1. 到下載資料夾雙擊 `install-windows.cmd`。
2. 若出現 SmartScreen「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。
3. 視窗會下載並安裝需要的元件（Python、yt-dlp、Deno、ffmpeg），最後顯示「安裝完成」。

**Mac**
1. 解壓縮下載到的 `install-mac.zip`。
2. 對 `install-mac.command` 按**右鍵 →「打開」**（直接雙擊會被 Gatekeeper 擋下）。若 macOS 15 以上仍被擋、只出現「無法打開」，請到「系統設定 → 隱私權與安全性」，往下找到這個檔案並按**「強制打開」**；或改用終端機（不會經過 Gatekeeper）：輸入 `bash `（後面有一個空格），把 `install-mac.command` 拖進視窗，按 Enter。
3. 需要系統有 `python3`（3.9 以上）。沒有的話，安裝檔會提示先在終端機執行 `xcode-select --install`。

### 3. 啟動

回到 Chrome，打開擴充功能，按**「啟動」**。狀態顯示「已啟動」就可以使用。

## 使用

1. 貼上網址：單支影片、播放清單、頻道網址（`youtube.com/@名稱`，會自動改查「影片」分頁），可多行。目前分頁是 YouTube 時，面板會出現「目前分頁」卡片，按「加入」就會放進網址框。解析完成後會先列出找到的影片，確認後再按「開始下載」。網址同時含影片與清單（`watch?v=…&list=…`）時只會取那一支；要整個清單請貼 `playlist?list=…` 網址。其中有無法解析的網址（例如私人影片）時，其餘照常下載，無法解析的會標示原因。
2. 選擇解析度（720p 或 1080p）。選 1080p 但影片只有 720p 時，會下載 720p，不算失敗。
3. 單支影片時，可以修改檔名（預設為影片標題）。頻道或播放清單可填「最多下載 N 支」。
4. 按**「開始下載」**。整體進度與每支影片的進度、剩餘時間會顯示在「下載清單」；中途關掉側邊面板，下載會繼續（關閉 Chrome 才會中止，重跑時會從中斷處續傳、跳過已完成的影片）。
5. 檔案預設放在「下載」資料夾下的 `YT下載`，可在面板下方的「設定與工具」修改。
6. 如果顯示「下載引擎可能過舊」，按**「更新下載引擎」**。YouTube 常改版，引擎需要定期更新。

檔名規則：Windows 不允許的字元會換成 `_`；太長的標題會截短；已有同名但不同影片時，檔名後面加上 ` [影片ID]`。

## 冒煙測試（請在你自己的電腦做一次）

1. 安裝並啟動，確認狀態顯示「已啟動」，並顯示 yt-dlp 版本、沒有「找不到 ffmpeg」「找不到 JS 執行環境」的警告。
2. 貼一支**公開的短影片**，選 720p，按開始下載。確認檔案出現、檔名是影片標題、可以播放，面板顯示的高度是 720。
3. 貼一個**小的播放清單**，選 1080p，最多 3 支。確認三支都下載完成，檔名都是各自的標題。
4. 再按一次下載，確認顯示「已下載過，略過」。
5. 貼一支私人或已刪除的影片，確認顯示明確的失敗原因，且不影響其他影片。
6. 「下載部署」的下載動作若沒有反應，請回報（程式已有備援方式，但尚未在真實 Chrome 驗證）。

## 疑難排解

| 狀況 | 處理 |
|---|---|
| 狀態顯示「尚未部署」 | 先按「下載部署」並執行安裝檔，完成後再按「啟動」 |
| 狀態顯示「Chrome 拒絕連線」 | 擴充功能識別碼與安裝檔不符，請重新按「下載部署」並再執行一次安裝檔 |
| 顯示「找不到 JS 執行環境」或「引擎過舊」 | 重新執行安裝檔，或按「更新下載引擎」 |
| 顯示「YouTube 要求登入或驗證」 | 這是 YouTube 對該網路的限制。請改用住宅或公司網路，不要用雲端或 VPN |
| Windows 安裝時 yt-dlp 無法執行 | 可能缺少 Visual C++ 執行階段，或被防毒軟體攔截 |
| 公司電腦無法安裝 | IT 可能限制了開發人員模式擴充功能、腳本執行或 Native Messaging，需請 IT 協助 |

## 開發

```bash
pip install -r requirements-dev.txt
python -m pytest                          # host 與建置腳本測試
node --test extension/tests/*.test.mjs    # 擴充功能純邏輯測試
npm i --no-save playwright-core@1.56.1    # e2e 需要（Chromium 位置可用 PW_CHROMIUM 指定）
node extension/tests/e2e/sidepanel.e2e.mjs  # 無頭 Chromium 端對端測試（假引擎）；結束碼 2 代表無法啟動瀏覽器；設 E2E_SHOTS=資料夾 會順便截圖，E2E_SCHEME=dark 測深色模式
python build.py                           # 修改 host 程式碼後重新產生安裝檔，並提交 extension/installers/
```

- `host/`：Native Messaging 小程式（只用 Python 標準函式庫）。
- `extension/`：Chrome 擴充功能（Manifest V3）。
- `build.py`、`installers/templates/`：產生單檔安裝檔，內嵌 host 程式碼。測試會檢查已提交的安裝檔與最新程式碼一致。
- `docs/superpowers/`：設計文件與實作計畫。
